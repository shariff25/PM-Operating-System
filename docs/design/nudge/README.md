# Nudge, the PM OS mascot

Approved by the owner on 2026-11-20. A sticky note that grew legs, got a lanyard, and follows
up on everything: the app's green rounded square with a folded corner, big eyes, a blush and a
work badge.

- `sheet.svg` / `sheet.png`: the character sheet (four poses, icon sizes, colours).
- `nudge.svg`: the hero pose.
- `generate.py`: draws both files (`python3 generate.py` in this folder). The poses are
  `hello`, `nudge`, `yay` and `calm`; the parts (eyes, mouth, arms, body) are plain functions.

Poses and where they belong: hello (onboarding), the gentle nudge (reminders and follow-ups),
approved (a draft was sent), suspiciously calm (nothing needs you).
