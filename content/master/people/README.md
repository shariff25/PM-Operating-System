# Personal master context

Each PM can add `people/<handle>/AGENTS.md`. PM OS loads it after the team's
`master/AGENTS.md`, so it can add to the team rules but not override them (CTX-3). Keep it
short:

```markdown
# <Name>'s context

## Areas I own
- e.g. Billing and payments, enterprise SSO, POCs for the EMEA region

## How I like drafts
- e.g. Lead with the customer problem; keep PRDs under 6 pages
```

Your personal file is visible to the team in git. Put nothing Restricted in it.
